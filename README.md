# AI Character Studio

A browser-based 3D character editor prototype for Android tablets and desktop browsers.

## Prototype features
- Three.js viewport with orbit, zoom and reset
- Realistic / anime presentation modes
- Adjustable body proportions, height, hair length
- Skin and hair color swatches
- Outfit and environment presets
- Lighting intensity control
- Randomize character
- Capture PNG snapshots

## Deployment
GitHub Actions deploys the site to GitHub Pages after commits on `main`.

Enable Pages in repository Settings → Pages → Build and deployment → Source: **GitHub Actions** if required.

The current model is a geometric placeholder/prototype, not a photorealistic sculpt or AI image generator. Higher-detail meshes, rigging, facial controls, textures and pose editing are planned.
